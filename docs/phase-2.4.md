# Phase 2.4 — About the Project and Support the Creator

Roadmap 3.0 places this phase after the News & Events release and before
Community. The first Preview adds bilingual pages at `/about` and
`/about/support`, accessible from the main menu, the Home footer and the
About page itself.

The Support page explains the possible uses of voluntary contributions,
including a future goal of funding X API credits for editorial discovery.
The owner chose one-time voluntary contributions via Ko-fi. The public
profile is still being prepared. Set `SUPPORT_KOFI_URL` to its public HTTPS
profile URL on the Phase 2.4 Preview branch after the owner confirms the
destination. When the value is absent or invalid, the page displays the
unavailable state. Payments are handled off-site on Ko-fi.

Validate both routes in English and Brazilian Portuguese. Check the desktop
and mobile navigation, the entry from the Home footer, and the canonical and
robots metadata. The Preview omits these routes from the sitemap. Production
includes them when the pages are released.

Once the profile is ready, verify the button and one-time contribution option
in both languages on Preview, up to the Ko-fi payment screen. Set the value for
Production and release only after the owner's approval. Recheck both routes and
the public sitemap on the official domain after release.
